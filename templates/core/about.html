About the Platform

Academic capstone project documenting architecture, design principles, and data governance.

1. Project Objective & Vision

The Market Databank Generation and Sharing Platform is an academic web platform designed to facilitate the collection, curation, indexing, previewing, and secure exchange of market-oriented datasets. Academic researchers and computer science students frequently face hurdles accessing reliable, structured tabular data across volatile economic sectors—such as daily stock market movements, agricultural crop yields, cryptocurrency liquidity, real estate indices, and macroeconomic trends.

This platform eliminates this friction by providing a self-service data sharing hub with built-in data validation, automatic schema detection, dynamic visualization, and strict confidentiality controls.

3. CSV Validation & Ingestion Pipeline

To maintain data integrity and protect the server against corrupt uploads, every submitted file executes through a strict validation sequence:

Extension & Size Filter
The system checks for the .csv extension and strictly limits file size to 10 Megabytes to prevent denial-of-service via resource exhaustion.
Encoding & Byte Stream Decoding
Files are verified across UTF-8, UTF-8-SIG (Excel BOM), and Latin-1 encodings. Non-text or binary files are rejected immediately.
Dialect Sniffing & Header Extraction
The standard library csv.Sniffer analyzes sample byte buffers to determine delimiters (comma, semicolon, tab). The first row is validated as non-empty column headers.
Metadata Indexing & Tabular Preview
Row counts, column counts, and column names are stored in the database record, and the first 20 rows are rendered into an interactive preview table on the details page.

4. Public vs. Private Data Governance

Data security is enforced at the database query and view handler levels:

  • Public Datasets: Accessible to any registered user for browsing, previewing, and direct CSV downloading.
  • Private Datasets: Completely isolated in database queries. Only the original author can access the details, view the preview, edit metadata, or download the CSV. Any unauthorized request raises an HTTP 403 PermissionDenied exception.
  • Secure File Streaming: Files are delivered via Django's FileResponse attachment stream rather than unprotected media directory links.
